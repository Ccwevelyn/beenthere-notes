## **<font style="color:rgb(255,0,0);">一、Data Codec and Data Transmission modes</font>**
>  "Data Codec" ：数据编解码器
>
>  "Data Transmission modes" ：“数据传输模式”  
>

**编解码器（Codec）**是一种技术，用于将**数据或信号**从一种**形式转换**为另一种形式。Codec 是"coder-decoder" 或 "compressor-decompressor" 的缩写，主要用于音频和视频处理。

例如，当你播放一段视频时，Codec 会将压缩的文件解压缩成可播放的格式；同样，当你录制视频时，Codec 会将原始数据压缩成更小的文件以便存储和传输。

**All of the forms** can be represented by **<font style="background-color:#FBDE28;">bit patterns</font>** (101011001…)

+  **Text and numbers**：ASCII or Unicode, etc.
+   **Image **：A **matrix of pixel**s（像素）, each pixel is assigned a **bit pattern**.

> + **像素矩阵（matrix of pixels）**：这是一个由许多像素组成的<u>二维数组</u>.                                          <font style="color:#DF2A3F;"> 像素是图像的最小单位</font><font style="color:#2F4BDA;">（ 像素是最小的图像构建单元  ）</font>，每个像素代表图像中的一个点。
> + **位模式（bit pattern）**：** ****<font style="background-color:#FBDE28;">是由一组比特（0和1）组成的序列</font>****，用于表示特定信息**。在数字图像处理中，<u>每个像素通常由多个比特（bits）表示</u>，这些比特共同构成了像素的颜色和亮度信息。_ eg. 如果我们有一个8位的位模式，它可以表示256种不同的状态（2的8次方），这对于灰度图像来说，可以表示从黑到白的256个灰度级别。  _

### <font style="color:rgb(0,0,0);">Digital Data and Signals（数字数据，数字信号）</font>
[https://blog.csdn.net/u010783226/article/details/119423968](https://blog.csdn.net/u010783226/article/details/119423968)

<font style="color:rgb(0,0,0);">The process of converting </font>**<font style="color:rgb(0,0,0);background-color:#FBDE28;">digital data to digital signals</font>**<font style="color:rgb(0,0,0);"> is called </font>**line coding****<font style="color:rgb(0,0,0);">.</font>**

>  线编码（Line Coding）是一种数据传输技术，它涉及**将数字数据转换为**适合在传输介质上传输的**电信号**。线编码的目的是确保信号能够有效地传输和接收，线编码确保信号在传输过程中保持完整且易于解码，同时降低误码率和信号失真。
>

+ <font style="color:rgb(0,0,0);"> A sequence of discrete, discontinuous voltage pulses                                                            数字信号是离散的非连续电压脉冲序列</font>

> 数据通过一系列**电压脉冲**来表示，每个脉冲代表一个比特（0或1）。这些脉冲在时间上是非连续的，这意味着在脉冲之间可能有间隙。  
>

+ <font style="color:rgb(0,0,0);">Each pulse is a signal element  一个脉冲就是一个信号元素。</font>
+ <font style="color:rgb(0,0,0);">Binary data encoded into signal elements </font>

> <font style="color:rgb(0,0,0);">二进制数据在传输时要把每个数据比特都编码成信号元素，</font><font style="color:#DF2A3F;">比特和信号元素之间存在一一对应的关系。</font>
>
> e.g.二进制的1由低电平表示，0由高电平表示。
>

#### <font style="color:rgb(0,0,0);">NRZ</font><font style="color:rgb(0,0,0);">(Non-Return-to-Zero) 不归零码</font>
:::success
<font style="color:rgb(0,0,0);">To use two different voltages for 0 and 1 bits 不同电平表示两个二进制数</font>

<font style="color:rgb(0,0,0);">Voltage constant during bit interval 电压在一个比特周期不改变</font>

**<font style="color:rgb(0,0,0);">No transition (no return to zero voltage)</font>**

:::

>  NRZ是一类编码技术的总称，其特点是在每个比特周期内，信号电平保持不变，不一定返回到零电平。NRZ编码可以进一步分类为不同的类型，其中包括NRZ-L和NRZ-I。  
>

+ <font style="color:rgb(0,0,0);">两个不同的电平表示两个二进制数字</font>
+ <font style="color:rgb(0,0,0);">The signal does not return to zero at the middle of the bit，一个比特周期内电平恒定</font>

### <font style="color:rgb(0,0,0);">Digital Data, Analog Signal（模拟数据，数字信号）</font>

<font style="color:rgb(0,0,0);">– uses modem (modulator-demodulator)</font>

> <font style="color:rgb(0,0,0);">这种传输方式最常见的应用是通过</font>**<font style="color:rgb(0,0,0);">公用电话网传输数字数据</font>**<font style="color:rgb(0,0,0);">。</font>
>
> <font style="color:rgb(0,0,0);">电话网的设计是为了在300~3400Hz的话音频率范围内接受、交换以及传输模拟信号。电话网并不是现成可以用来处理来自用户端的数字信号的。因此，数字设备需要通过调制解调器与网络相连，实现数字数据与模拟信号的相互转换。</font>

### <font style="color:rgb(0,0,0);">Analog Data, Digital Signal（模拟数据，数字信号）</font>
+ <font style="color:rgb(0,0,0);"> Digitization（数字化） is conversion of analog data into digital data </font>

<font style="color:rgb(0,0,0);">– Analog data, such as voice and video, is often digitized to be able to use digital transmission facilities. </font>

+ <font style="color:rgb(0,0,0);">Analog to digital conversion done using a </font>**<font style="color:rgb(0,0,0);">codec （编解码器）</font>**

编解码器：用于将模拟数据转换成可传输的数字形式，或相应地将数字信号恢复成原始模拟数据。

两种编解码器使用的主要技术:

<font style="color:rgb(0,0,0);">– Pulse Code Modulation (PCM)脉码调制</font>

<font style="color:rgb(0,0,0);">– Delta Modulation (DM) 增量调制</font>

### <font style="color:rgb(0,0,0);">Analog Data, Analog Signals（模拟数据，模拟信号）</font>
<font style="color:rgb(0,0,0);">Analog data can be modulated by a </font><font style="color:rgb(0,176,240);">carrier frequency </font><font style="color:rgb(0,0,0);">to produce an analog signal in a different frequency band, which can be utilized on an analog transmission system. </font>

<font style="color:rgb(0,0,0);">模拟数据可以通过载波频率调制以产生不同频带的模拟信号，该信号可用于模拟传输系统。</font>

+ <font style="color:rgb(0,0,0);">Why modulate analog signals? </font>

<font style="color:rgb(0,0,0);">– Higher frequency can give more efficient transmission (carrier frequency relates to antenna size) </font>

<font style="color:rgb(0,0,0);">– Permits frequency division multiplexing </font>

<font style="color:rgb(0,0,0);">– </font><font style="color:rgb(0,0,0);">Amplitude modulation (AM) </font>

<font style="color:rgb(0,0,0);">– </font><font style="color:rgb(0,0,0);">Frequency modulation (FM) </font>
