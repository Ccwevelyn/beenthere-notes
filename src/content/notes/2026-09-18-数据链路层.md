**链路（Link）**就是从一个结点到相邻结点的一段物理线路，而中间没有任何其他的交换结点。

**数据链路（Data Link)** = 链路 + 实现通信协议的硬件和软件

数据链路，以**帧**为单位，进行传输

2. 差错检测

发送方将封装好的帧通过物理层发送到传输媒体，帧在传输过程中遭遇干扰后可能会出现误码。（如，比特反转）- 主机如何发现误码？→ 检错码

检错码：4字节的帧检验序列 - FCS字段

接收方收到帧后，通过检错码和检错算法就可以判断出帧在传输过程中是否出现了误码。

3. 可靠传输

接收方主机收到有误码的帧 - 丢弃

如果数据链路层向上层提供的是不可靠传输服务 - 丢弃即可

但是，如果提供的是可靠传输服务 - 丢弃后还需采取措施，使得其接收到被丢弃帧的正确副本

+ 尽管误码是不能避免的，但是若能实现发送方发送什么，接收方就能收到什么，就成为可靠传输。

3. 为了提高帧的传输效率，应当使帧的数据部分长度尽可能大。

因为帧的数据部分才是希望传输的内容，而帧头和帧尾只是为了实现数据链路功能而额外添加的。

考虑到差错控制等多种因素，每一种**数据链路协议**都规定了<u>帧的数据部分的长度上限</u>，即**最大传输单元MTU（Maximum Transfer Unit）**

**透明传输与 MTU 的共存**

+ **透明传输的作用**：
    - 数据链路层不会对上层数据施加内容上的限制，透明地接受任何数据类型或格式。
    - 但是，它会根据 MTU 将数据分片，以适应底层网络的物理限制。
+ **MTU 的作用**：
    - 数据链路层将传入的数据封装成帧时，会检测帧的大小是否超出了 MTU。
    - 如果数据超过 MTU，链路层会将数据拆分成多个帧（分片），以确保能够传输。

###### 奇偶校验
在待发送的数据后面添加**<font style="color:#DF2A3F;">1位奇偶校验位</font>**，使整个数据（包含所添加的校验位在内）的“1”的个数为

奇校验 - 1的个数为奇数

偶校验 - 1 的个数为偶数

检错码只能检测出帧在传输过程中出现了差错，但并不能定位错误，因此无法纠正错误。

#### 可靠传输的基本概念
差错检测技术（如循环冗余校验CRC）=>接收方的数据链路层可检测出误码

如何处理？ ---取决于数据链路层向上层提供的服务类型

 <!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2025/png/42556572/1744006141571-e873bded-1f18-4793-9a4e-9f8d179df488.png)

1. 不可靠传输服务：仅仅丢弃有误码的帧
2. 可靠传输服务：想办法实现发送方发送什么，接收端就受到什么

**注意**：（一般情况下）

+ <u>有线链路</u>的**误码率**比较**低**，为了减小开销，并<u>不要求</u>数据链路层向上提供可靠传输服务。即使出现了误码，可靠传输的问题由其上层处理。
+ <u>无线链路</u>易受干扰，**误码率**比较**高**，因此要求数据链路层<u>必须向上层提供</u>可靠传输服务。

**<u>传输差错类型</u>**

1. 比特差错
2. 分组丢失
3. 分组失序
4. 分组重复（超时重发 --> 分组重复）

后三者，一般不会出现在数据链路层，而会出现在上层。

每层都可以选择实现/不实现可靠传输。

![](https://cdn.nlark.com/yuque/0/2025/png/42556572/1744006560590-7e6390e4-218b-42e4-ae3f-9e4f1686b9c0.png)

可靠传输的实现比较复杂，开销也比较大，是否使用可靠传输取决于应用需求。

### 二、媒体接入控制
#### 基本概念
总线型局域网，主机共享&竞争总线，**信号**在共享媒体上**碰撞** -- 发生冲突 =>站点发送失败

**共享信道**要着重考虑的一个问题就是**如何协调**多个发送和接受站点对一个共享传输媒体的**占用**，即协调<u>媒体介入控制MAC（Medium Access Control）</u>

###### 频分复用FDM
频分复用的所有用户同时占用不同频带并行通信。

<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2025/png/42556572/1744015542383-58a8acc3-1b99-4703-83f1-8aeb6a90bf54.png)

隔离频带 - 避免信号干扰

复用器：将<u>每一路信号</u>调制到_不同频率的载波 _上

分用器：通过滤波，将各路信号分开；将合成的复用信号恢复成原始的多路信号。

| 特性 | 独立使用线路 | 频分复用（FDM） |
| --- | --- | --- |
| **线路需求** | 每个信号独占一条线路 | 多个信号共享同一条线路 |
| **资源利用率** | 利用率低，空闲时无法复用 | 利用率高，多个信号可以同时传输 |
| **技术复杂度** | 低，只需简单的物理连接 | 高，需要频率分配、滤波器和调制/解调技术 |
| **成本** | 线路数量直接影响成本，基础设施成本高 | 线路数量减少，综合成本较低 |
| **适用场景** | 小型、简单的网络需求 | 大型网络、高带宽需求场景（如电视广播） |


 频率分配可以根据需求动态调整，而独立线路一旦建成，灵活性较差。

存在碰撞问题，解决手段：

##### 载波监听多址接入/碰撞检测 CSMA/CD
Carrier Sense Multiple Access / Collision Detection

###### 多址接入 MA
多个站连接在一条总线上，竞争使用总线

###### 载波监听 CS
每一个站在**发送**帧**之前先检测**一下总线上是否有其他站点在发送帧 -- “先听后说”

+ 若检测到总线空闲96比特时间，则发送这个帧
+ 若检测到总线忙，则继续检测并等待总线转为空闲96比特时间，然后发送这个帧。

96比特时间 => 发送96bit需要的时间~帧间最小间隔

+ 作用：使接收方可以检测出一个帧的结束，同时也使得所有其他站点都能有机会平等竞争信道并发送帧。

###### 碰撞检测 CD
每一个正在发送帧，边发送边检测碰撞 --“边说边听”

+ 发现碰撞，立即停止发送，退避一段随机时间后，再次发送。

由网络设备制造商生产时烧录在网卡中。

> MAC地址的长度为48位（6个字节），通常用12个16进制数表示，如：00-50-56-C0-00-08。其中前3个字节（00-50-56）代表网络硬件制造商的编号，后3个字节（C0-00-08）代表该制造商所制造的某个网络产品(如网卡)的序列号。
>
> 因此，MAC地址如同公民身份证号码，具有唯一性。用于标识网络设备在网络中的位置。
>

用户主机一般包含两个网络适配器：有限/无线 -->每个都有全球唯一的MAC地址

#### <font style="color:#DF2A3F;">IP和MAC地址的区别</font>
| IPv4 address | MAC address |
| --- | --- |
| network layer | link layer |
| 32bits | 48bits |
| a.b.c.d/24 | flat address |
| subnet+host | FF.FF.FF.FF.FF.FF |
| DHCP-动态分配 | manufacture |
| not portable | portable |
| DNS: hostname->IP address | ARP: IP address ->MAC address |


 Flat address系统中的所有地址处于同一个平面，没有分段或层次。例如，每个地址都是独立的，没有区域或子网的区分。  

相比于分层地址（例如IP地址带有子网和网络层级结构），flat address的设计更直接，没有路径信息或逻辑区域的划分。因此，扩展性和路由效率可能较低，但对于简单场景来说更高效。  

 MAC地址是物理地址，与设备硬件绑定（通常是网卡）。无论设备连接在哪个网络中，MAC地址始终保持不变。这使得MAC地址具备真正的“便携性”，可以跨网络识别设备。

无源电缆、大量机械接头的总线型以太网 => 不可靠

**无源电缆（Passive Cable）**是一种不包含任何电子元件或放大器的电缆，其功能完全依靠电缆的物理特性来传输信号。  

+ **无源电缆**：信号完全依赖物理介质传输，成本低，但距离有限。
+ **有源电缆**：内置电子元件，可以放大信号或实现数据转换，支持更长的传输距离，但价格更高。

=>可靠性低、淘汰！！！

#### 以太网交换机
<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2025/png/42556572/1744108432669-cd6d7d23-9515-4992-8e19-018071f568e2.png)

HUB：主机--发送单播帧-->主机；该单播帧会通过共享总线传输到**<u>总线上的其他各个主机</u>**

SWITCH: 交换式以太网；单播帧转**<u>发至目的主机</u>**

+ 通常，有多个接口。每个接口都可以通过**双绞线电缆**与一台主机/另一台以太网交换机相连。
+ 全双工方式，发送/接收帧同时进行。
    - 注意：使用**HUB**的以太网在逻辑上是共享总线的，需要使用CSMA/CD协议来协调各主机争用总线，只能工作在半双工模式。

_详解：_

**<u>HUB</u>**

+ HUB是一个广播设备，它将接收到的数据转发到连接的所有端口。
+ 在同一时间，只有一个设备可以发送数据，而其他设备必须等待。
+ 如果两个设备同时发送数据，会发生冲突（collision），导致数据丢失。

**<u>Switch</u>**

在全双工模式下，冲突被有效避免，因为发送和接收的数据在物理上隔离或逻辑上独立

**<u>总结</u>**

+ HUB：依赖广播通信，采用<font style="color:#DF2A3F;">半双工</font>模式，容易冲突，效率较低。
+ Switch：采用点对点通信，支持<font style="color:#DF2A3F;">全双工</font>模式，通信更高效，性能更优。

#### 对比
1. 主机发送单播帧

HUB：**单播帧**会**传播**到总线上的其他**各主机。各主机**中的**<u>网卡</u>**根据**帧的目的MAC地址**（与自己的MAC地址比对）决定是否接受该帧。

SWITCH：交换机根据**目的MAC地址**和自身的**帧交换表（走哪个接口），**将帧转发给目的主机

2. 碰撞 

HUB：产生碰撞，遭遇碰撞的帧会传播到总线上各主机

SWITCH：交换机收到多个帧时，会将它们缓存起来，然后逐个转发给目的主机，不会产生碰撞。

**集线器在物理层？**

集线器（HUB）被归类为**物理层设备**的原因主要在于它的功能和工作方式符合OSI模型中物理层的定义：

**1. 数据的处理方式**

+ **物理层的职责**是传输原始的比特流（0和1），而不涉及任何数据帧的解读或地址识别。
+ 集线器只负责接收、放大（如果需要），然后将数据比特流广播到所有连接的端口。它不关心数据的内容或目标地址。

**2. 不具备智能**

+ 集线器的行为非常简单，只是机械地复制和转发数据，没有判断或解析数据帧的能力。
+ 它不会处理MAC地址（链路层）或IP地址（网络层），也没有路由或交换功能。

**3. 与交换机的对比**

+ 交换机属于数据链路层设备，因为它能够解析数据帧并根据MAC地址进行智能转发。
+ 集线器则完全基于物理层，只负责将接收到的电信号分发给所有连接的设备。
