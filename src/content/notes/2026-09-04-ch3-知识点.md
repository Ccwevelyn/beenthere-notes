##### DOM --> MVVM
DOM v.s. MVVM => **自动绑定 vs 手动绑定**

```javascript
let username = "Congwen";
document.getElementById("nameDisplay").innerText = username;
username = "Evelyn"; //更改数据
document.getElementById("nameDisplay").innerText = username;
//更改完数据之后，需要手动告知页面 -> 告知数据更改，请找新数据
```

```vue
data() {
  return {
    username: "Congwen"
  };
}

this.username = "Evelyn"; //更改数据，不需要告知 -- 自动同步
```

 更新由框架负责  <font style="color:rgb(0, 0, 0);"> Vue updates the view efficiently.</font>

**Model** - Data layer -> Raw data

**View** - The structure, layout, and appearance of what a user sees on the screen.

**ViewModel** ->  Data processing

<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2025/png/42556572/1760269397113-cd9f26c1-66d7-49a4-8baa-c7b1d07e310b.png)

数据（Model）≠ 处理数据的逻辑（ViewModel），而界面（View）又不应该承担数据处理职责，所以需要一个中介层——ViewModel。  

```javascript
export default {
  data() { 
    return {
      username: "Congwen"  //Model
    };
  },
  computed: {
    greeting() {
      return `Hello, ${this.username}`; //ViewModel
    }
  },
  methods: {
    updateName(newName) {
      this.username = newName;
    }
  },
  template: `<p>{{ greeting }}</p>`  // VIEW 界面
}
```

#### Node.js & NPM
Node.js  是一个**运行 JavaScript **的**服务器环境**，它的核心作用是：

+ 让你在本地或服务器上运行 JS（<u>不依赖浏览器</u>）
+ 提供开发工具（比如构建、打包、测试）
+ 支持包管理系统（npm）

NPM（Node Package Manager）是 Node.js  附带的工具，它可以：

+ 下载并安装开源库（比如 Vue、React、Axios 等）
+ 管理依赖版本
+ 组织项目结构（通过 `package.json`）

NPM 是一个**<font style="color:#2F4BDA;">工具</font>**，它本身并不“内含” Vue，而是提供了一个机制来安装和管理 Vue 这样的库。

+ **npm（Node Package Manager）** 是一个**<u>包管理工具</u>**，它连接到一个**<font style="color:#2F4BDA;">远程仓库</font>**（npm registry），里面存放了成千上万的 JavaScript 库，包括 Vue。
+ 当你执行 `npm install vue` 时，npm 会去 registry 下载 Vue 的源码包，并把它放到你的项目中。

所以 Vue 是一个**独立的 npm 包**，而 npm 是**安装它的工具**

2. computed - 基于data的派生状态

**只读**属性（不能直接赋值），适合封装复杂逻辑。**<font style="color:#2F4BDA;">不可传参</font>**

`**<font style="color:#2F4BDA;">computed</font>**`** **的“参数”其实是它**自动依赖的响应式数据 data()**

`computed: { isHot() { ... } }` 是怎么调用的？

这是 Vue 的**计算属性机制**，它的调用方式是：

+ Vue 会**<font style="color:#2F4BDA;">自动调用</font>** `isHot()`，并把返回值作为 `vm.isHot` 的值
+ 它是一个**只读属性**，你可以在模板或代码中<u>直接访问它</u>

```javascript
computed: {
  isHot() {  //没有参数！！！
    return this.temperature > 30;
  }
}
```

+ 在模板中你可以写：`<p>{{ isHot }}</p>`

✅ 不需要你手动调用 `isHot()`，Vue 会自动执行并缓存结果

=> 布尔值，返回true/false

#### 生命周期钩子（如 mounted, created, updated)
 **生命周期钩子**是 Vue 在组件运行的不同阶段**自动调用**的函数  

 <u>你只需要定义它们，Vue 会在合适的时机触发</u>。  

| `created` | **实例创建后** | 初始化数据、调用 API、启动定时器 |
| --- | --- | --- |
| `mounted` | **DOM 挂载后** | 操作 DOM、启动定时器 |
| `updated` | **响应式更新后** | 处理更新后的副作用 |
| `unmounted` | **组件销毁前** | 清理资源、移除监听器 |


```javascript
mounted() {
  console.log('组件已经挂载到 DOM');
}
```

+ 当组件挂载到页面时，Vue 会自动调用它
+ 你不需要手动执行 `mounted()`，Vue 会帮你做

#### this 指向
 在 `computed`、`methods`、生命周期钩子中，`this` 指向组件实例  

| 在 `**computed**` 中访问响应式数据 | Vue 自动追踪 `this.xxx`的依赖 |
| --- | --- |
| 在 `methods`中访问组件状态 | `this`指向组件实例，包含 `data`, `props`, `computed` 等 |
| 在生命周期钩子中访问数据或调用方法 | `this`是组件上下文 |
| 在模板表达式中间接访问方法或属性 | Vue 会自动绑定 `this`到组件实例 |


```vue
methods: {
  greet(name) {
    console.log(`Hello, ${name}`);
  },
  init() {
    this.greet(this.username); // ✅ 在方法中调用另一个方法
  }
},
  mounted() {
    this.init(); // ✅ 在生命周期钩子中调用方法
  }
```

this 在 Vue 中指向的是**组件实例**

当你调用 `Vue.createApp(...).mount('#app')`，Vue 会创建一个组件实例

Vue 中，`methods` 是挂载在组件实例上的    

<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2025/png/42556572/1760323418384-973032ad-dd5f-4155-8eb3-741224444225.png)

`mounted`** 是一个生命周期钩子（hook），它是组件选项中的一个独立字段，不属于 **`methods`。

Vue 会在组件挂载到 DOM 后**自动调用**`mounted()`，你只需要在组件选项中定义它

V-model 主要用于**处理用户输入**，并实现数据的**双向绑定**

<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2025/png/42556572/1760332686108-9088b319-0be6-489f-9243-95e049c88fb6.png)

`v-model` 让你不需要手动监听 `input` 或 `change` 事件，也不需要手动更新数据。

`v-model` 的作用是**把用户输入或选择的值绑定到组件的数据属性中**，而你是否显示它是**视图层的选择**，并不影响你在逻辑层使用它。  

| 文本输入框 | `<input v-model="">` |
| --- | --- |
| 多行文本框 | `<textarea v-model="">` |
| 复选框 | `<input type="checkbox" v-model="">` |
| 单选框 | `<input type="radio" v-model="" value="A">` |
| 下拉菜单 | `<select v-model="">` |
